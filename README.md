## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um **dashboard de vendas no Power BI**, utilizando bases de dados fictícias relacionadas a **vendas, clientes, produtos e funcionários**.

O objetivo principal foi praticar conceitos de **modelagem de dados, relacionamentos entre tabelas, criação de visualizações e análise de informações**.

O projeto faz parte do meu processo de aprendizado em Power BI e representa uma das primeiras aplicações práticas dos conhecimentos adquiridos durante meus estudos.

---

## 🎯 Objetivos

Durante o desenvolvimento do projeto, os principais objetivos foram:

- Praticar a importação de dados;
- Explorar o Power Query;
- Criar e organizar um modelo de dados;
- Trabalhar com relacionamentos entre tabelas;
- Desenvolver um dashboard com múltiplas páginas;
- Utilizar diferentes tipos de visualizações;
- Aplicar filtros e segmentações;
- Desenvolver uma apresentação visual organizada dos dados.

---
